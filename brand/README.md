# brand/

Your brand packs: one folder per brand, e.g. `brand/acme/` with `brand.md` (who you are, voice, audience, hard
rules, chosen voice), `MOTION.md` (colours, type, timing, motion rules) and any logos or fonts. Claude reads the
pack before it designs anything for that brand.

Start from `.claude/skills/forge-reels/templates/brand-pack-template/`, or look at the filled-in fictional
example in `.claude/skills/forge-reels/templates/brand-pack-example/`. Details: `references/brand-packs.md` in
the skill.
